# وب‌سایت محب‌المهدی

قالب استاتیک فارسی و راست‌چین برای انتشار در GitHub Pages؛ بدون نیاز به Node.js، پایگاه داده یا سرور.

## فایل‌ها
- `index.html` — صفحه اصلی
- `style.css` — ظاهر، رنگ‌ها و واکنش‌گرایی
- `script.js` — منوی موبایل و سال جاری
- `blog.html` — صفحه مقاله‌ها با جست‌وجو و فیلتر
- `posts.js` — فهرست مقاله‌ها؛ برای افزودن مورد تازه این فایل را ویرایش کن
- `blog.js` — نمایش و جست‌وجوی کارت‌ها
- `assets/logo.jpg` — لوگوی اختصاصی شما
- `404.html` — صفحه خطای 404
- `.nojekyll` — جلوگیری از پردازش Jekyll در حالت انتشار از شاخه

## پیش از انتشار این موارد را شخصی‌سازی کن
1. لینک تلگرام `https://t.me/mohebalmahdi_ir` و شناسه نمایشی `@mohebalmahdi_ir` از قبل تنظیم شده‌اند.
3. معرفی، پروژه‌ها و مهارت‌ها را با اطلاعات دقیق و نمونه‌کارهای واقعی خودت جایگزین کن.
4. در `posts.js` عنوان‌ها و خلاصه‌های نمونه را با نوشته‌های خودت جایگزین کن. برای هر مقاله کامل، یک فایل HTML جدا بساز و مسیرش را در `url` قرار بده.
5. اگر ایمیل نمایش‌داده‌شده را عوض کردی، تمام لینک‌های `mailto:` را هم به‌روز کن.

## انتشار روی مخزن فعلی
مخزن هدف:
`https://github.com/mohebalmahdi-ai/mohebalmahdi-ai.github.io`

### روش ساده با مرورگر
1. ZIP را از حالت فشرده خارج کن.
2. وارد مخزن GitHub شو و شاخه `main` را باز کن.
3. از **Add file → Upload files** استفاده کن و تمام فایل‌ها و پوشه‌های بسته را بارگذاری کن؛ ساختار پوشه `assets` را حفظ کن.
4. اگر GitHub پرسید، فایل‌های موجود را با نسخه جدید جایگزین کن.
5. در پایان **Commit changes** را بزن.
6. در **Settings → Pages** بررسی کن که انتشار از شاخه `main` و پوشه `/(root)` تنظیم شده باشد.
7. پس از پایان انتشار، این نشانی را باز کن: `https://mohebalmahdi-ai.github.io/`

راهنمای رسمی GitHub Pages:
